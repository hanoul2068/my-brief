# 우리 다이어리 (couple-diary)

TimeTree처럼 배우자와 일정·일기를 함께 쓰는 앱입니다.
다른 점은 **데이터를 자체 서버가 아니라 아이폰 기본 캘린더(iCloud)에 직접 저장**한다는 것입니다.

## 왜 이렇게 만들었나

TimeTree는 자기 서버에 일정을 저장하기 때문에, 애플 캘린더·위젯·Siri·다른 앱에서는 TimeTree 일정이 안 보이거나 일방향 구독만 됩니다.
이 앱은 iOS 시스템 캘린더(EventKit)에 바로 기록하므로:

- 애플 캘린더, 홈 화면 위젯, 잠금화면, Siri, CarPlay, 애플워치에 바로 표시
- 구글 캘린더·Outlook·Fantastical 등 시스템 캘린더를 읽는 모든 앱과 자동 연동
- 반대로 다른 앱에서 등록한 일정(구글, 회사 Exchange, 공휴일 등)도 이 앱에 함께 표시
- 배우자와의 공유는 **iCloud 공유 캘린더**가 처리 → 서버·회원가입·비용 없음

## 기능

| 탭 | 기능 |
| --- | --- |
| 📅 캘린더 | 월간 달력(색상 막대), 좌우 스와이프로 월 이동, 날짜별 일정 목록, 일정 추가/수정/삭제, 하루 종일·반복(매일/매주/매월/매년)·알림·장소·메모, 반복 일정은 "이 일정만/이후 모두" 선택, 작성자 표시(✍️ 남편) |
| 📔 일기 | 날짜·기분 이모지·본문으로 일기 작성, 월별 목록, 내 일기/배우자 일기 색 구분 |
| ⚙️ 설정 | 내 이름, 기본 공유 캘린더 선택, "우리 캘린더"/"우리 일기장" iCloud 캘린더 생성, 캘린더별 표시 on/off, 공유 방법 안내 |

앱이 다시 열릴 때마다 자동 새로고침하므로 배우자가 추가한 내용이 바로 보입니다.

## 처음 설정 (최초 1회)

1. 앱 실행 → 캘린더 권한 **전체 접근** 허용
2. 설정 탭 → 내 이름 입력 → "우리 캘린더 새로 만들기", "우리 일기장 새로 만들기"
3. 아이폰 **캘린더 앱** → 하단 "캘린더" → 만든 캘린더의 ⓘ → "사람 추가" → 배우자 Apple ID, **편집 허용** 켜기
4. 배우자가 초대 수락 → 배우자 폰에도 앱 설치 → 설정에서 같은 캘린더 선택

> TimeTree의 기존 일정은 자동으로 옮겨지지 않습니다. 앞으로의 일정을 "우리 캘린더"에 등록하거나, 중요한 반복 일정(기념일·생일 등)만 다시 입력하는 것을 추천합니다.

## 실행 방법

```bash
cd couple-diary
npm install
npx expo start
```

- 아이폰에 **Expo Go** 앱을 설치하고 터미널에 나온 QR 코드를 카메라로 찍으면 바로 실행됩니다.
- 앱스토어 없이 내 폰에 정식 앱으로 설치하려면: `npx eas-cli@latest build --platform ios --profile preview` (Apple 개발자 계정 필요)

## 구조

```
App.tsx                 탭 화면 + 권한 화면
src/calendar.ts         시스템 캘린더 읽기/쓰기 (expo-calendar), 작성자·일기 형식
src/store.tsx           캘린더 목록·권한·새로고침 (앱 복귀 시 자동)
src/settings.tsx        내 이름·기본 캘린더 등 로컬 설정 (AsyncStorage)
src/components/         월간 달력, 날짜 선택 등
src/screens/            캘린더 / 일정 편집 / 일기 / 설정 화면
```

### 데이터 형식

- 일정: 일반 캘린더 이벤트. 메모 마지막 줄에 `✍️ 이름`으로 작성자 기록
- 일기: "우리 일기장" 캘린더의 하루 종일 이벤트. 제목 = `기분이모지 이름: 첫 줄`, 메모 = 본문
  → 이 앱이 없어도 애플 캘린더에서 그대로 읽을 수 있습니다.

## 한계 / 다음 단계 아이디어

- 일정별 댓글·사진 첨부, 활동 알림(“아내님이 일정을 추가했어요”)은 iCloud 캘린더로는 불가 → 필요하면 Firebase 같은 백엔드를 추가해야 함
- 이벤트별 색상 라벨은 EventKit이 지원하지 않아 캘린더 색상을 사용 (라벨이 필요하면 캘린더를 여러 개 만들어 구분)
- 홈 화면 위젯은 애플 캘린더 위젯을 그대로 쓰면 됨
